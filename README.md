Welcome to the official repository for the **Arqulat** landing page. Arqulat is a unified elite startup engineering the next generation of autonomous systems, agentic workflows, and immersive 3D digital frontiers.

This project showcases a high-fidelity, professional frontend interface that balances a cinematic "cosmic" aesthetic with a structured, GitHub-inspired technical architecture.

## 🌟 Key Technical Features

### 1. Immersive Cosmic Interface
- **Global Galaxy Background:** A stable, performant star field with periodic, technical comet animations (triggered every 10s) that traverse the viewport diagonally.
- **Atmospheric Depth:** Layered mesh-drift gradients providing cinematic background textures without compromising content readability.

### 2. Advanced 3D & Physics Animations
- **Orbital Capability System:** A custom Helium-atom inspired orbital navigation system featuring 3D tilted rings and interactive nodes.
- **Adaptive 3D Tilt:** Bento-style cards and team profiles utilize `framer-motion` springs for real-time, cursor-aware 3D transformations.
- **Interactive Glare:** High-end glass-glare effects that sweep across technical modules on hover.

### 3. Professional Structural Alignment
- **GitHub-Fidelity Box Model:** Consistent use of high-contrast backgrounds (`#161b22`) and precise 1px borders (`#30363d`).
- **Strategic Pipeline:** A vertical, Git-style roadmap demonstrating the journey from service roots to a unified startup engine.
- **Normalized Typography:** Standardized professional font scaling using `Geist` for headings and `JetBrains Mono` for technical metadata.

### 4. Seamless User Experience
- **Smooth Navigation:** precision anchor-scrolling with calculated offsets for sticky headers.
- **High-Performance Motion:** Integrated **Lenis** smooth-scrolling paired with hardware-accelerated animations for a 120FPS feel.

## 🚀 Getting Started

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SivaGaneshv1729/arqulat.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```

### Development

Start the development server with Hot Module Replacement (HMR):
```bash
npm run dev
```

### Production

Create a high-performance production build:
```bash
npm run build
```
